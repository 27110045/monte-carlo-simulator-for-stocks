This project uses Geometric Brownian Motion to simulate future stock prices. It downloads historical price data of the stock and uses it to calculate its volatility and past growth, and then gives us 1000 possible future values of the stock. The output shows all the 1000 price simulations, and the mean final price,value at risk, as well as the probability that the stock ends with a value higher than the start period. This project clearly shows through outputs for different time periods that the mathematical model gives you an output strongly based on whatever data you feed it.
